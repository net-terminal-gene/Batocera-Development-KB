# Vertical games that are also in the Fightcade library

Built 2026-09-30 from `/Volumes/Batocera/SETUP/fightcade/roms` and `/Volumes/Batocera/vertical/roms`.

Fightcade zip ids are short names. The vertical library usually uses the full title. A row is included only when one of these is true:

1. The same zip id is in both libraries.
2. The scraped titles match after ignoring case, punctuation, and a leading The.
3. A regional title was checked in the Fightcade description or in the files inside the zip.

Sequel titles were not folded together. Joust 2 is not Joust. Super Raiden is not Raiden.

DoDonPachi Dai-Ou-Jou (`ddpdoj.zip`) is in the vertical MAME folder and is not in this Fightcade FBNeo folder. Fightcade does have `donpachi.zip`, `ddp2.zip`, and `ddp3.zip`.

No match: Dreamcast (Fightcade's folder is fighters and sports; the vertical folder is shmups), PC Engine CD (no Fightcade folder, and the HuCard set does not contain those discs), Atomiswave, Game Gear, Master System, MSX, SG-1000, SuperGrafx, ZX Spectrum, ColecoVision, Naomi 2.
